# 다형성(Polymorphism) 학습 프로젝트

객체지향 프로그래밍의 핵심 원리 중 하나인 다형성을 코드를 통해 학습하고, 그 장점을 이해하기 위한 프로젝트입니다.

## 목적

-   오버로딩(Overloading)과 오버라이딩(Overriding)의 차이점을 이해합니다.
-   인터페이스(Interface)와 추상 클래스(Abstract Class)를 활용하여 다형성을 구현하는 방법을 익힙니다.
-   다형성을 통해 코드의 유연성과 확장성이 어떻게 향상되는지 학습합니다.
-   `if-else`나 `switch` 문으로 분기 처리를 하던 코드를 다형성을 이용해 어떻게 개선할 수 있는지 알아봅니다.

## 기술 스택

*   **Language**: Java
*   **Testing**: JUnit 5

## 핵심 학습 내용

이 프로젝트는 역할(인터페이스)과 구현(클래스)을 분리하는 것의 중요성을 보여줍니다.

예를 들어, `PaymentMethod`라는 인터페이스가 있고, 이를 구현하는 `CreditCardPayment`, `BankTransferPayment`, `MobilePayment` 등의 클래스가 있을 수 있습니다. 클라이언트 코드는 구체적인 결제 클래스를 몰라도 `PaymentMethod` 인터페이스 타입만으로 다양한 결제 방식을 처리할 수 있게 됩니다.

이를 통해 새로운 결제 방식이 추가되더라도 기존 클라이언트 코드의 변경 없이 기능을 확장할 수 있는 OCP(개방-폐쇄 원칙)를 실현하는 방법을 학습합니다.
