# Spring 공부 기록 📚

자바와 스프링을 공부하면서 여러 개념과 기술을 직접 구현해보는 프로젝트입니다. 개인적인 학습 내용을 정리하는 용도입니다.

---

### 프로젝트 목록

*   **BaseSpring**: 스프링 프로젝트의 가장 기본적인 설정을 잡아보는 프로젝트.

*   **enum-setter**: Enum 타입에 Setter를 사용하지 않고 안전하게 값을 관리하는 방법에 대한 고민.

*   **jpa**: JPA 기본 개념과 여러 연관관계 매핑 학습. 복잡한 매핑도 다뤄보려고 노력했습니다.

*   **ObjectAndProcedure**: 객체지향과 절차지향 프로그래밍의 차이점을 코드로 비교하며 이해하기.

*   **Polymorphism**: 다형성의 장점을 활용해서 코드를 어떻게 더 유연하게 만들 수 있는지 실험해본 프로젝트.

*   **SpringBatch**: 대용량 데이터 처리를 위한 Spring Batch 기본 예제. 간단한 Job과 Step을 만들어봤습니다.

*   **TokenBuckit**: 토큰 버킷 알고리즘을 이용한 API 요청 제한 (Rate Limiting) 구현.

*   **Transact Cache**: 트랜잭션 환경에서 캐시를 어떻게 사용해야 하는지 테스트. `@Transactional`과 캐시의 상호작용을 중심으로 살펴봤습니다.

*   **ValueObject**: 값 객체(Value Object) 패턴을 사용해 코드의 안정성과 표현력을 높이는 방법을 연습했습니다.
