# BaseSpring 프로젝트

Spring Boot를 사용한 가장 기본적인 프로젝트 구조입니다.

## 목적

다른 스프링 프로젝트를 시작할 때 기본 템플릿입니다.

## 기술 스택

*   **Framework**: Spring Boot 3.5.3
*   **Language**: Java 17
*   **Database**: H2 (In-memory)
*   **Dependencies**:
    *   Spring Web
    *   Spring Data JPA
    *   Lombok

## 실행 방법

프로젝트를 실행하면 내장된 H2 데이터베이스와 함께 웹 애플리케이션이 시작됩니다.
